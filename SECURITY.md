# Security Policy

## Supported Versions

Only the latest published release of Dely is supported with security fixes.
Please upgrade to the latest release before reporting an issue.

## Reporting a Vulnerability

Please **do not** open a public GitHub issue for a security vulnerability.

1. **Preferred:** use [GitHub private vulnerability reporting](../../security/advisories/new)
   for this repository.
2. **Fallback:** if you cannot use GitHub private reporting, email
   contact@hieuphung97.com with a description of the issue, steps to
   reproduce, and its potential impact.

We will acknowledge your report, investigate, and follow up with next steps
and, where applicable, a fix and coordinated disclosure timeline.
